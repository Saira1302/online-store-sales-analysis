# Online-Store-Sales-Analysis


This project focuses on analyzing sales data to gain valuable insights into business performance. The dataset was cleaned, sorted, and visualized through a dashboard to identify key trends and patterns. The analysis provides information on:

Sales distribution across different cities

High revenue-generating product categories

Revenue breakdown by region

# Features of the Project

Data Cleaning: Removed missing values, handled duplicates, and ensured data consistency.

Data Sorting: Organized data for better readability and analysis.

Dashboard Creation: Built an interactive dashboard for visualizing insights.

City-wise Sales Analysis: Identified sales performance in different locations.

High Revenue-Generating Product Categories: Identified the product categories that generate the most revenue.

Revenue Analysis: Evaluated revenue trends based on regions.
